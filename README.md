# Pager

Заголовки русских и английских изданий на одной странице, в духе
brutalist.report, — для блогеров, которые ищут, о чём снимать. Мода, кино и
музыка, соцсети, бизнес, искусство, технологии, наука. Без политики.

Есть русская (`/ru`) и английская (`/en`) версии: английские заголовки
переведены на русский, русские на английский. Оригинал переведённого
заголовка виден во всплывающей подсказке, язык оригинала — серой меткой у
названия сайта. Читают в основном с телефона, вёрстка сначала под 390px.

```
sources.json          разделы и фиды — единственное, что правится руками
cmd/server            запуск, настройки из переменных окружения
internal/feeds        разбор sources.json, загрузка RSS/Atom (ETag/If-Modified-Since)
internal/translate    запросы к Polza.ai: перевод с пометкой политики, кэш переводов
internal/digest       проход «фиды → переводы → снимок», раз в REFRESH
internal/ideas        «Тренды» — темы по разделам из свежих заголовков
internal/web          страница (html/template), стили, иконка — всё вшито в бинарник
```

## Страница

Сверху вкладки: «Тренды» и разделы. Под вкладкой раздела — его сайты: «Все»
или один; под «Трендами» — разделы. Выбор живёт в адресе
(`/ru?t=fashion&s=2`, `/ru?t=trends&s=film`), так что ссылкой можно
поделиться, а «назад» работает. Сервер рендерит HTML, JS нет.

У каждого заголовка — возраст («35 мин», «5 ч»), серым.
Шрифт — Verdana (на Android — системный Roboto).

Тема — как в системе; солнце/луна в шапке переключает её и запоминает в
куке `theme` (ссылка `/theme?to=light&back=…`, возврат только на свой путь).

## Как устроено

Go-сервер без базы. Раз в 15 минут качает все фиды параллельно, берёт по
20 свежих заголовков с источника, отсеивает политику, оставляет 10 и
собирает снимок в памяти — его и отдаёт страница. Не ответил фид —
остаются заголовки с прошлого раза.

**Перевод.** Переводятся только новые заголовки, пачками по 40 (до 4 пачек
параллельно), моделью `anthropic/claude-haiku-5.5` через Polza
(`POST /v1/chat/completions`, справочник —
`~/content/video_factory/docs/polza-api.md`). Готовые переводы лежат в
`data/translations.json` и чистятся через две недели без использования.

**Без политики.** В том же запросе на перевод модель ставит каждому
заголовку пометку «про политику» (власть, выборы, законы, санкции, войны,
протесты, геополитика). Помеченные не показываются. Новый заголовок
появляется после проверки; если Polza недоступна и источнику нечего
показать, заголовки идут без проверки. Что считать политикой — в промпте,
`internal/translate/polza.go`.

**Тренды.** Раз в 8 часов заголовки каждого раздела (уже без политики)
уходят модели `anthropic/claude-sonnet-5.5` — по запросу на раздел,
параллельно. Она выбирает до 3 тем, лучшую первой, и предпочитает темы, о
которых пишут сразу несколько изданий: что случилось, три подхода к теме
(без привязки к формату — ролик, пост, сценарий), исходные заголовки.
Промпт запрещает жаргон («хук», «залетит») и уход от темы раздела. Сразу на двух языках. Во
«Всех» — лучшая тема каждого раздела, в разделе — все его темы. Не ответил
раздел — у него остаются прошлые темы. Результат — в `data/ideas.json`,
после рестарта не пересобирается. Промпт — в `internal/ideas/ideas.go`.
Пока трендов нет, сайт открывается на первом разделе.

Без `POLZA_AI_API_KEY` нет ни перевода, ни фильтра, ни идей — всё в оригинале.

## Источники

`sources.json`: разделы и фиды в них, порядок на странице тот же. У фида
`lang` — язык оригинала (`ru`/`en`), `name_en` — название для английской
версии, если отличается. Файл вшит в бинарник; для правок без пересборки —
`SOURCES=/path/to/sources.json`. Ошибка в файле роняет запуск с понятным
сообщением.

Новостной раздел убран — это почти сплошь политика. В «Кино и музыке» нет
русских источников (KinoNews, Film.ru, PEOPLETALK): там в основном новое
российское кино, а оно аудитории не интересно. Не взяты из-за
закрытых или отсутствующих фидов: Vogue Russia, Glamour, GQ, AD, Business of
Fashion, HBR, РБК (403), Elle.ru, Harper's Bazaar Russia, Wonderzine,
Тинькофф Журнал (не отвечают), Артгид, It's Nice That, Later, The Flow,
Кинопоиск (нет RSS). Не взяты по смыслу: Zero Hedge, Vox (политика),
Phoronix, Slashdot (слишком узко).

## Запуск локально

Локальный Go старый (1.20), поэтому через Docker. Порт — только на
localhost:

```bash
docker build -t pager .
docker run --rm -p 127.0.0.1:8095:8080 -e POLZA_AI_API_KEY=... -v pager-data:/data pager
# http://localhost:8095
```

Тесты:

```bash
docker run --rm -v "$PWD":/src -v pager-gomod:/go/pkg/mod -w /src golang:1.27-alpine go test ./...
```

## Настройки

| Переменная | По умолчанию | |
|---|---|---|
| `POLZA_AI_API_KEY` | пусто | пусто — без перевода, фильтра и идей |
| `TRANSLATE_MODEL` | `anthropic/claude-haiku-5.5` | перевод и пометка политики |
| `IDEAS_MODEL` | `anthropic/claude-sonnet-5.5` | «Тренды» |
| `IDEAS_EVERY` | `8h` | как часто пересобирать тренды |
| `REFRESH` | `15m` | как часто обходить фиды |
| `PER_SOURCE` | `10` | заголовков на источник (качается вдвое больше — запас на отсев политики) |
| `SOURCES` | вшитый `sources.json` | путь к своему списку |
| `CACHE_PATH` | `data/translations.json` (`/data/…` в Docker) | кэш переводов |
| `IDEAS_PATH` | `data/ideas.json` (`/data/…` в Docker) | последние идеи |
| `ADDR` | `:8080` | |

## Прод

Как остальные проекты — за общим Caddy из `edge`:

1. A-запись домена → IP сервера.
2. На сервере: `.env` с `POLZA_AI_API_KEY`, затем
   `docker compose -f docker-compose.prod.yml up -d --build`.
3. В `edge/caddy/Caddyfile`:
   ```caddy
   pager.weektum.com {
   	import site
   	reverse_proxy pager-web:8080
   }
   ```
   и `docker compose exec caddy caddy reload --config /etc/caddy/Caddyfile`.

`/healthz` отвечает 503, пока не собран первый снимок.
